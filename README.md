# PvZ Pinyin — browser reimplementation

An unofficial, work-in-progress browser reimplementation of the iPad game Plants vs. Zombies Pinyin Adventure. The implementation was developed with AI assistance and uses observations from the original game and reverse engineering.

This repository contains HTML, CSS, and JavaScript only. Original game artwork, audio, fonts, and game-derived JSON data are not included. Consequently this checkout cannot run the game completely by itself. The empty asset directories are placeholders; adding resources does not grant any rights to use or distribute them.

The implementation is incomplete and has not been fully verified against the original hardware. This project is not endorsed by or affiliated with EA, PopCap, or their licensors. No license for original game content is granted here. Third-party code and data require separate review before reuse.

`dist/native-random-sort.js` references Adobe AVMplus `core/ArrayClass.cpp`; its provenance and applicable licensing require further review.
